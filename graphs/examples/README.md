# Example Projects

This directory contains example Cascade projects to help you get started.

## Loading Examples

1. Open Cascade
2. Press **⌘O** (or **Ctrl+O**) to open a project
3. Navigate to `graphs/examples/`
4. Select an example file (`.cascade.json`)

## Available Examples

### hello-world.cascade.json
A simple example connecting a Timer node to a Viewer node.

**What it does:**
- Timer node triggers every second
- Viewer node displays the trigger events
- Demonstrates basic node connection

**Try it:**
1. Open the project
2. Double-click the Timer node
3. Modify the interval value
4. See the changes in real-time

### counter.cascade.json
A counter that increments on each timer tick.

**What it does:**
- Timer triggers every 500ms
- Counter increments on each trigger
- Viewer displays the current count
- Demonstrates stateful nodes

**Try it:**
1. Open the project
2. Watch the counter increment in the console
3. Edit the Counter node to add a reset function
4. Experiment with different timer intervals

## Creating Your Own Examples

1. Create a new project in Cascade
2. Build your graph
3. Save it as `.cascade.json` in this directory
4. Share it with others!

## Tips

- All examples use relative paths for assets
- Examples are self-contained (no external dependencies required)
- You can modify any example and save it as a new file
- Check the console for node logs and outputs
